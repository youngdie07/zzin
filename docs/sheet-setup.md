# 에디터 분류 시트 사용법

식당별 분류(맛 스타일, 가성비, 손님층, 팁, 상황, 키워드, 추천 메뉴, 한줄평)를 시트에 적으면 앱에 자동 반영됩니다.
시트에 값이 있으면 **리뷰 집계보다 에디터 분류가 우선**하고, 칸을 비워두면 리뷰 집계를 그대로 씁니다.

## 1. 시트 만들기
1. 구글 시트에서 새 스프레드시트 > 파일 > 가져오기 > 업로드 > `docs/restaurant-template.csv`
2. (선택) 확장 프로그램 > Apps Script 에 `docs/sheet-dropdowns.gs` 를 붙여넣고 `addDropdowns` 실행 -> 칸마다 드롭다운이 생겨요.

## 2. 채우기 (허용 값)
| 칸 | 값 |
|---|---|
| 영업상태 | 영업중 / 폐업 (비우면 변경 없음) |
| 맛 스타일 | 한국 맛 그대로 / 반반 / 현지화됨 |
| 가성비 | 가성비 좋음 / 가격만큼 / 아쉬움 |
| 손님층 | 한국인 많음 / 반반 / 현지인 많음 |
| 팁 | 팁 안 받아요 / 팁 포함 / 팁 선택 / 팁 필수 |
| 상황 (여러 개: 쉼표) | 가족 모임, 차별 없음, 한국인 입맛 |
| 키워드 (여러 개: 쉼표) | 한국어 주문 가능, 양 푸짐, 반찬 리필, 주차 편함, 웨이팅 적음, 웨이팅 김, 혼밥 OK, 소주·술 OK, 아이 동반 OK, 단체·회식 OK, 예약 필수, 깔끔·청결, 직원 친절, 늦게까지 영업, 포장 편함 |
| 추천 메뉴 (여러 개: 쉼표) | 자유 입력 |
| 한줄평 | 자유 입력 |

- 새 식당은 줄을 추가하세요. 식당명(영문), 음식 종류, 주소는 꼭 필요하고 위도/경도는 없으면 오스틴 중심으로 들어가요.
- 식당명(영문)이 기존 식당과 같으면 그 식당을 수정하고, 시트에 없는 식당은 건드리지 않아요.
- 잘못된 값은 무시하고, 서버 로그나 `npm run sheet:sync` 출력에 "몇 행 어느 식당 어느 칸"으로 알려줘요.

## 3. 앱과 연결
1. 파일 > 공유 > 웹에 게시 > 시트 선택, 형식 **CSV** > 게시 > 링크 복사
   (링크를 아는 사람은 읽을 수 있지만 수정은 못 해요)
2. `backend/.env` 에 `SHEET_CSV_URL=복사한 링크` 추가
3. 서버를 다시 켜면 시작할 때와 이후 10분마다(`SHEET_SYNC_MINUTES`) 자동으로 반영돼요.
   바로 반영하려면 `cd backend && npm run sheet:sync`

시트 없이 파일로만 쓰려면 CSV를 엑셀/넘버스로 편집한 뒤 `SHEET_CSV_URL=../docs/restaurant-template.csv` 처럼 파일 경로를 넣으세요.
