# 에디터 분류 시트 사용법

식당별 분류(본토 느낌, 한국인 입맛, 입맛 포인트, 가성비, 손님층, 팁, 상황, 키워드, 추천 메뉴, 주문 팁, 한줄평)를 시트에 적으면 앱에 자동 반영됩니다.
시트에 값이 있으면 **리뷰 집계보다 에디터 분류가 우선**하고, 칸을 비워두면 리뷰 집계를 그대로 씁니다.

**운영 시트:** [ZZIN 식당 분류](https://docs.google.com/spreadsheets/d/1pDehuaphRl2SdDfH6obf-NgajmuvX12xg3ZByOFESbg/edit) (드롭다운·메모 설정 완료, `backend/.env.example` 에 연결돼 있음)
처음 한 번만: 시트 오른쪽 위 **공유 > 일반 액세스 > 링크가 있는 모든 사용자 (뷰어)** 로 바꿔야 서버가 읽을 수 있어요.

맨 앞 **요약** 탭은 식당 탭을 수식으로 집계해요 (전체·한식·지역·출처·입력 상태·칸별 입력 현황). 손댈 필요 없어요.

아래는 시트를 새로 만들 때의 방법이에요.

## 1. 시트 만들기
1. 구글 시트에서 새 스프레드시트 > 파일 > 가져오기 > 업로드 > `docs/restaurant-template.csv`
2. (선택) 확장 프로그램 > Apps Script 에 `docs/sheet-dropdowns.gs` 를 붙여넣고 `addDropdowns` 실행 -> 칸마다 드롭다운이 생겨요.

## 2. 채우기 (허용 값)
| 칸 | 값 |
|---|---|
| 입력 상태 | 자동 계산이라 적지 않아요. 세부 종류·가격대·분류 칸이 모두 비어 있으면 **리뷰 미입력**, 하나라도 있으면 **검증필요** |
| 세부 종류 (한식만) | 종합 한식 / 고기구이 / 순두부·찌개 / 국밥·탕 / 치킨 / 분식 / 포차·술집 / 반찬·도시락 / 퓨전 |
| 가격대(1인) | $10 미만 / $10–20 / $20–30 / $30–50 / $50–100 / $100 이상 (비우면 앱에 가격 표시 안 함) |
| 영업상태 | 영업중 / 폐업 (비우면 변경 없음) |
| 본토 느낌 | 본토 맛 그대로 / 반반 / 미국식 (바비큐는 미국식 대신 체인점 스타일도 가능). 원래 그 나라에서 먹는 맛과 비교해요. 한식이면 한국 맛 기준 |
| 한국인 입맛 | 잘 맞아요 / 무난해요 / 안 맞아요 |
| 입맛 포인트 (여러 개: 쉼표) | 많이 짜요, 많이 달아요, 느끼해요, 매콤해요, 담백해요, 밥 생각나는 맛, 국물 있음, 해장 가능 |
| 가성비 | 가성비 좋음 / 가격만큼 / 아쉬움 |
| 손님층 | 한국인 많음 / 반반 / 현지인 많음 |
| 팁 | 팁 안 받아요 / 팁 포함 / 팁 선택 / 팁 필수 |
| 상황 (누구랑, 여러 개: 쉼표) | 가족 모임, 부모님 모시고, 아이 동반, 데이트, 회식·단체, 혼밥, 차별 없음 |
| 키워드 (여러 개: 쉼표) | 한국어 주문 가능, 양 푸짐, 반찬 리필, 주차 편함, 웨이팅 적음, 웨이팅 김, 소주·술 OK, 예약 필수, 깔끔·청결, 직원 친절, 늦게까지 영업, 포장 편함 |
| 추천 메뉴 (여러 개: 쉼표) | 자유 입력 |
| 주문 팁 | 자유 입력 (120자까지). 예: 덜 짜게(less salt) 해달라고 하세요 |
| 한줄평 | 자유 입력 |
| 출처 | 구글맵 저장목록 / 초기 한식 목록 / 둘 다 / 직접 추가. 앱에는 안 쓰이고 요약 시트 집계용 |

- 예전 이름(맛 스타일 칸, 한국 맛 그대로 / 현지화됨)도 계속 인식해요.

- 새 식당은 줄을 추가하세요. 식당명(영문), 음식 종류, 주소는 꼭 필요하고 위도/경도는 없으면 오스틴 중심으로 들어가요.
- 식당명(영문)이 기존 식당과 같으면 그 식당을 수정하고, 시트에 없는 식당은 건드리지 않아요.
- 폐업한 곳은 줄을 지우기 전에 영업상태를 **폐업**으로 바꿔 한 번 동기화하세요. 그래야 앱 목록에서도 사라져요.
- 잘못된 값은 무시하고, 서버 로그나 `npm run sheet:sync` 출력에 "몇 행 어느 식당 어느 칸"으로 알려줘요.

## 3. 앱과 연결
링크 공유 시트는 `https://docs.google.com/spreadsheets/d/<시트ID>/export?format=csv&gid=<탭ID>` 형식으로 넣어도 돼요. 또는:
1. 파일 > 공유 > 웹에 게시 > 시트 선택, 형식 **CSV** > 게시 > 링크 복사
   (링크를 아는 사람은 읽을 수 있지만 수정은 못 해요)
2. `backend/.env` 에 `SHEET_CSV_URL=복사한 링크` 추가
3. 서버를 다시 켜면 시작할 때와 이후 10분마다(`SHEET_SYNC_MINUTES`) 자동으로 반영돼요.
   바로 반영하려면 `cd backend && npm run sheet:sync`

시트 없이 파일로만 쓰려면 CSV를 엑셀/넘버스로 편집한 뒤 `SHEET_CSV_URL=../docs/restaurant-template.csv` 처럼 파일 경로를 넣으세요.
