# 내 후기 → 분류 기준

시트 **내 후기 (줄글)** 칸에 후기를 적고 Claude에게 "후기 분류해줘"라고 하면, 입력 상태가 **후기 분류 대기**인 줄을 읽어 아래 기준으로 칸을 채워요.

## 채우는 방법
- 후기에 근거가 있는 칸만 채워요. 언급이 없으면 기존 값을 그대로 둬요 (AI가 추정한 값도 유지).
- 후기와 기존 값이 다르면 **후기가 우선**이에요.
- 한줄평은 비어 있을 때만 후기를 한 문장으로 줄여 넣어요. 이미 적힌 한줄평은 건드리지 않아요.
- 다 채우면 **검증완료**를 체크하고 AI 메모를 `내 후기 기반 분류 YYYY-MM-DD · 바꾼 칸: …`으로 바꿔요. 앱에는 '찐 에디터 선정'으로 나가요.
- 후기만으로 판단이 어려운 칸은 비워두고 AI 메모에 적어요.
- 내 후기 원문은 앱에 나가지 않아요.

## 칸별 기준
| 칸 | 후기에서 이런 말이 나오면 |
|---|---|
| 한식 스타일 | 요즘 한국에서 먹는 맛·메뉴 → **요즘 한국 스타일** / 옛날 맛, 이민 1세대 느낌, 오래된 집 → **그 시절 한국 맛** / 달다, 미국 사람 입맛, 퓨전 → **미국식 한식** |
| 가성비 | 싸다, 양 대비 만족 → **가성비 좋아요** / 낸 만큼 → **적당해요** / 비싸다, 특별한 날 → **가격대 있어요** |
| 손님층 | 한국 사람이 대부분 → 한국인 많음 / 섞여 있음 → 반반 / 현지인이 대부분 → 현지인 많음 |
| 팁 | 카운터 주문·키오스크 → 팁 선택 / 서빙 → 팁 필수 / 노팁 → 팁 안 받아요 / 서비스 차지 → 팁 포함 |
| 상황 | 혼자 → **혼밥** / 친구·연인·데이트 → **친구랑** / 아이·키즈 메뉴 → **아이 동반** / 가족 모임·부모님·회식·여럿 → **단체** |
| 키워드 | 시트 허용 값 중 후기에 나온 것 ([sheet-setup.md](sheet-setup.md)) |
| 추천 메뉴 | 맛있다고 한 메뉴 (최대 8개) |
| 주문 팁 | "이렇게 시키세요" 류의 조언 (120자) |
| 가격대·세부 종류 | 후기에 금액이나 종류가 나오면 맞춰 고쳐요 |
